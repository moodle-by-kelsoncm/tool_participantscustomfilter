Instalação
==========

Passo a Passo
-------------

1. Clone o repositório no diretório de ferramentas administrativas:

   .. code-block:: bash

      cd /caminho/do/moodle/admin/tool
      git clone https://github.com/moodle-by-kelsoncm/tool_participantscustomfilter.git participantscustomfilter

2. Execute a atualização via linha de comando:

   .. code-block:: bash

      php admin/cli/upgrade.php --non-interactive
