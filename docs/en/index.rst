Overview - moodle-tool_participantscustomfilter
=================================================

**moodle-tool_participantscustomfilter** is an administration plugin for Moodle that enhances the search capabilities on the course participants page (`/enrol/index.php`), enabling **filtering by custom user profile fields**.

Key Features
------------

- **Filter by Custom Profile Fields**: Adds dropdowns and search inputs based on custom profile fields created on the platform.
- **Built-in AMD JS Module**: Client-side logic developed as an asynchronous AMD module (`filter.js`).
- **Native List Integration**: Intercepts and applies filters directly to the standard course participants roster.
